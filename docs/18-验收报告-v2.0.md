| 642d8d9 | **bat 改 CRLF 最小版** + .gitattributes | LF+echo 重定向致 cmd 解析失败 |
| 8c0dbbe | **重连后自动重订阅** + 连接健康主动退出 + 告警降噪 | 断线 1 小时不恢复 |
| 694cc8b | **单实例端口锁** + 日终跳过防刷屏 | 多实例风暴 |

**最有价值的三条工程教训**（已沉淀）：
1. **Windows 批处理必须 CRLF**（LF + 重定向行会让 cmd 静默拒绝整个脚本）；
2. **CTP 断线重连 ≠ 恢复订阅**（重登后必须重新 SubscribeMarketData）；
3. **单实例互斥是兜底刚需**（任务调度的防重不可信，端口锁是硬保证）。
