## 2. B. 核心独立验证（组合引擎）

### B1 约束前逐笔一致性 ★ 决定性验证

方法：对 8 个品种分别做**单品种独立回测**，取其「首次约束事件」之前的全部成交，与组合引擎中该品种的成交逐笔比对（日期 / 动作 / 价格 / 手数四元组全等）：

| 品种 | 首事件日期 | 约束前成交（独立 vs 组合） | 逐笔一致 |
|---|---|---|---|
| RB0 | 2025-05-22 | 115 vs 115 | ✅ True |
| I0 | 2025-06-26 | 97 vs 97 | ✅ True |
| M0 | 2025-05-28 | 95 vs 95 | ✅ True |
| P0 | 2025-10-13 | 115 vs 115 | ✅ True |
| SR0 | 2025-08-04 | 109 vs 109 | ✅ True |
| MA0 | 2025-05-23 | 119 vs 119 | ✅ True |
| TA0 | 2025-06-05 | 135 vs 135 | ✅ True |
| AL0 | 2025-06-09 | 103 vs 103 | ✅ True |

> **8/8 全部一致**：组合引擎在无约束环境下与单品种引擎行为**完全等价**——引擎正确性坐实。约束触发后的路径分歧（独立合计 -90,754 元 vs 组合 -94,490 元，差 -3,736 元）属保证金约束的**预期行为**。

### B2 财务一致性（闭合）

- 单测断言：`组合权益 − 初始资金 ≡ Σ品种盈亏 − 累计手续费`（开仓→平仓全链路）；
- 实测核对：100,000 → 期末约 2,003 元（-98.00%），与 `Σpnl(-94,490) − 手续费(3,507)` 完全闭合。

### B3 保证金约束机制（资金边界对照）

| 资金规模 | 成交笔数 | 约束事件 | 判定 |
|---|---|---|---|
| 500 万 | 1228 | **0** | ✅ 资金充裕 → 无拒绝 |
| 10 万（默认） | 1098 | 1060 | ✅ 亏损侵蚀后自 2025-05 起出现拒绝（首事件 2025-05-22） |
| 3 万 | 122 | **8719** | ✅ 资金收紧 → 约束显著增加（单调合理） |

### B4 头寸规模三模式（真实数据）

| 模式 | 约束事件 | 首个开仓手数（8 品种） |
|---|---|---|
| `fixed`（默认） | 1060 | 全部 1 手 |
| `equal_weight`（100 万） | 741 | RB10 / I10 / M10 / P9 / SR10 / MA10 / TA10 / AL6 |
| `inv_vol`（100 万） | 248 | RB10 / I7 / M10 / P8 / SR10 / MA10 / TA10 / AL4 |

> 三模式均真实数据跑通、手数符合「保证金预算 ÷ 单手保证金」口径；`inv_vol` 与 `equal_weight` 手数分布不同，权重逻辑生效。
