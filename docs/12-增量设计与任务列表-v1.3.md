### 3.3 bar 内处理时序（核心）

```mermaid
flowchart LR
    A["bar 事件（某品种）"] --> B["① 跳空检查<br/>已有止损：open 穿过 → 开盘价平仓"]
    B --> C["② 信号成交<br/>基础目标 → 停板/熔断/敞口/保证金 逐级调整"]
    C --> D["③ 盘中检查<br/>low/high 触发止损止盈 → 触发价成交"]
    D --> E["④ 盯市 + 移动止损更新<br/>（收盘后，次日生效）"]
    E --> F["⑤ 日终<br/>熔断判定 + 逐日风险记录"]
```

- **同日优先级**：跳空止损 > 信号成交 > 盘中止损（保守序，写入报告口径）；
- **新仓保护**：当日新开仓位自次日一交易日起才纳入盘中止损检查；
- **止损成交 = 平仓腿**：不受保证金限制；但受**停板方向约束**（§3.7，跌停日多头止损将"止不掉"，如实呈现）；
- 步骤 ⑤ 在全部品种处理完后执行一次（组合级判断）。

### 3.4 仓位管理（T1.3-1）

**ATR 风险预算（第 4 模式 `atr_risk`）**：

```
基础目标手数 = floor( 权益_t × risk_pct ÷ (k_stop × ATR_t × multiplier) )
```

- 输入全部取**截至信号日 t 收盘**的数据（ATR_t = 20 日 TR 均值），次日开盘执行——与现有信号口径一致，防未来函数；
- 手数管线（逐级调整，每步可记事件）：

| 步骤 | 规则 | 事件类型 |
|---|---|---|
| ① 基础目标 | ATR 风险预算公式 | — |
| ② 方向合规 | 停板方向不可成交（§3.7） | `limit_refuse` |
| ③ 熔断调整 | 暂停 → 0；减半 → max(1, floor(目标 × 0.5)) | `fuse_pause` / `fuse_degrade` |
| ④ 敞口截断 | 单品种 / 组合名义上限内截断；截至 1 手仍超 → 拒绝 | `exposure_trim` / `exposure_refuse` |
| ⑤ 保证金降级 | 按可负担手数降级；不足 1 手 → 跳过 | `margin_degrade` / `margin_refuse` |

**实测校准表（2026-10-10 本地缓存数据 · ATR(20) · 当前时点读数）**：

| 品种 | 最新价 | ATR(20) | 2×ATR 单手风险 | 1.5% 预算(1500元) | 2% 预算(2000元) |
|---|---:|---:|---:|---:|---:|
| RB0 螺纹 | 3,112 | 30.1 | 602 元 | 2 手 | 3 手 |
| SR0 白糖 | 5,354 | 49.4 | 987 元 | 1 手 | 2 手 |
| M0 豆粕 | 3,372 | 54.2 | 1,084 元 | 1 手 | 1 手 |
| TA0 PTA | 6,300 | 202.7 | 2,027 元 | 0 手 | 0 手 |
| I0 铁矿 | 702.5 | 11.4 | 2,280 元 | 0 手 | 0 手 |
| AL0 沪铝 | 23,830 | 232.3 | 2,322 元 | 0 手 | 0 手 |
| MA0 甲醇 | 2,972 | 125.0 | 2,499 元 | 0 手 | 0 手 |
| P0 棕榈 | 9,581 | 174.5 | 3,490 元 | 0 手 | 0 手 |

> **两个关键结论**：① 8 品种各 1 手、止损全部触发的合计风险 ≈ **15,291 元（15.3% 权益）**——风险预算存在的直接理由；② 10 万资金 + 单笔风险 1.5% 下，高波动品种（I0/AL0/TA0/MA0/P0）多数时段**开不了仓**——小资金 + 风险纪律的真实约束，报告如实呈现；`risk_pct` 可调（1%~3% 档位）。

**敞口上限**：开仓事前检查（截断 / 拒绝）；持仓后因价格变动超限仅逐日记录（`exposure_warn` 统计），不强制减仓。

### 3.5 止损止盈（T1.3-2）

| 类型 | 参数默认 | 触发判定 | 成交口径 |
|---|---|---|---|
| 固定止损 | 2×ATR（入场时冻结） | 多头 low ≤ 止损价 / 空头 high ≥ 止损价 | 跳空：open 穿过 → 按 open；盘中 → 按止损价 |
| 移动止损 | 3×ATR（持仓极值回撤；ATR 逐日更新，收盘后生效） | 同上 | 同上 |
| 止盈 | 固定比例（**默认关**） | 多头 high ≥ 止盈价 / 空头 low ≤ 止盈价 | 跳空 → open；盘中 → 止盈价 |

- **有效止损价** = max(固定止损, 移动止损)（多头；空头对称）；每根 bar 先跳空判定、后盘中判定；
- **同一 bar 止损与止盈均触及时按止损处理**（保守）；
- **重入规则**：止损触发的当日不再开仓；默认 `reentry: signal_reset`——需信号回到 0 或反向（重置）后才允许同方向重入（避免"止损-重入"循环；备选 `cooldown` / `immediate`）；
- **停板交互**：跌停日的多头止损（卖出方向）被拒 → 记录事件、持仓跨日、次日继续判定（"想止损止不掉"的真实风险）；
- 事件：`stop_fixed` / `stop_trailing` / `take_profit` / `stop_refused`，含触发读数与成交价。

### 3.6 组合熔断（T1.3-3）

| 档位 | 触发（每日收盘判定） | 动作（次日开盘生效） | 恢复 |
|---|---|---|---|
| L1 单日亏损 | 组合单日收益 ≤ −3% | 暂停新开仓（平仓正常） | 冷却 3 个交易日自动恢复 |
| L2 回撤 | 权益回撤 ≤ −15% | 新开仓目标减半（≥2 手目标才实际压缩，下限 1 手） | 回撤回落至 −10% 以内；或冷却 20 日（先满足者） |
| L3 连续亏损 | 组合级连亏平仓 ≥ 5 笔 | 暂停新开仓 | 冷却 10 个交易日 |
| LA 全平 | 回撤 ≤ −25%（**默认关**） | 全平全部持仓（次日开盘）→ 进入暂停冷却 | 冷却 10 日 |

- **优先级**：全平 > 暂停 > 减半（多级同时命中取最严）；恢复判定同样在每日收盘；
- 判定用当日收盘权益 / 收益，动作次日开盘执行——与全局时序一致（防未来函数）；
- 全部事件入 `risk_events`（含触发读数、动作、恢复日期）；报告给汇总统计。

### 3.7 涨跌停与流动性（T1.3-6）

- **停板近似**：`|当日收益| ≥ 品种停板幅度 × 0.95` 视为停板日（幅度按品种配置，交易所口径近似；无结算价，登记为口径风险）；
- **方向感知**：跌停日拒绝**卖出方向**成交（平多 / 开空）；涨停日拒绝**买入方向**成交（平空 / 开多）；对**信号单与止损单一视同仁**；
- **成交量参与率**：单笔下单手数 ≤ 当日成交量 × 5%（可配）；截断记事件（当前规模几乎不触发，作为容量设施种子）；
- 事件：`limit_refuse` / `participation_trim`。

### 3.8 压力测试（T1.3-4）

- **历史情景（数据驱动）**：自动识别样本期内组合「单日跌幅 Top3、5 日跌幅 Top3、波动率最高 3 段」（去重合并），输出两个口径：①**当时实际损失**（直接读权益曲线）；②**标准化重估**（按 1 手/品种名义敞口重演情景期品种收益）——口径并列写明，不混用；
- **假设情景**：① 跳空冲击：全持仓方向不利 −2σ / −3σ（σ = 近 60 日日收益波动）；② 连续 3 日跌停（按品种停板幅度步进重估）；③ 相关性跳升：全品种同日 −2σ 的「分散化失效」情形；
- **蒙特卡洛回撤分布**：对组合日收益序列做 iid bootstrap ×500 → 最大回撤分布（P50/P90/P95/P99）；复用 `stats_utils` 统计函数（组合版实现于 `stress.py` 内，不触单品种模块）；
- 输出：`stress_results.csv` + 报告表格 + `risk_stress.png`（情景损失条形 + 回撤分布直方，双面板）。

### 3.9 风险指标（T1.3-5）

- **VaR / CVaR**：历史模拟法、滚动 250 日窗口、95% / 99%；逐日计算（只用截至当日历史，防未来）；组合级 + 逐品种；
- **集中度**：逐日品种 / 板块名义敞口占比（板块映射见 config），报告峰值与峰值日期；
- **相关性预警**：滚动 60 日策略日收益平均相关 > 0.5 标记预警，报告预警天数与峰值；
- 输出 `risk_daily.csv`：date / equity / exposure_total / leverage / margin_util / fuse_state / var95 / var99 / cvar95 / cvar99 / drawdown / corr_mean60 / top_sector_share。

### 3.10 风控开 / 关对比（演示核心）

- `run_portfolio.py` 自动双跑：**A 裸奔**（fixed 1 手 · 风控全关 · 保证金约束保留）vs **B 全开**（ATR 风险预算 · 止损 · 熔断 · 约束）；
- 输出对比表（收益 / 回撤 / 夏普 / 最差单日 / 波动率 / 交易数 / 止损次数 / 熔断次数）+ `risk_compare.png`（权益与回撤双面板对比）+ `risk_compare.csv`；
- 口径说明注明：A→B 同时改变了「头寸方法」与「风控机制」，效果构成不作独立归因（后续可加中间口径）。

## 7. 风险与开放项

| # | 项 | 说明 |
|---|---|---|
| R1 | 盘中触价为 OHLC 近似 | 无法还原真实盘中路径；同 bar 多触发按保守序（止损优先）；口径已锁定并写入报告 |
| R2 | 停板近似（无结算价） | 阈值 ×0.95 的启发式；方向感知拒单为近似；登记为口径风险 |
| R3 | 熔断阈值需按基线校准 | 三级阈值 / `risk_pct` 为建议默认；实施时校准一次并留档 |
| R4 | VaR 历史模拟的滞后性 | 250 日窗口对极端行情反应滞后；报告注明方法局限 |
| R5 | 对比实验归因局限 | A/B 同时变更头寸方法与风控机制，不做独立归因（口径说明注明） |
| R6 | 重入规则影响路径 | `signal_reset` 会显著改变结果（趋势中断即出场）；备选 `cooldown` / `immediate` |
| R7 | 小资金品种覆盖 | 高波动品种多数时段开不了仓——如实呈现；`risk_pct` 档位可调 |
