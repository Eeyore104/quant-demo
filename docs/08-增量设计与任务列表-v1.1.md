## 1. 目标

把「过拟合体检」从一半补到完整：四件套（样本外 ✓ 已有 / 参数敏感性 / 蒙特卡洛 / 成本敏感性）+ Deflated Sharpe 校正；报告一键输出「体检」章节，逐项判定 通过 / 存疑 / 不通过。

## 2. 设计决策（关键口径）

| 项 | 口径 |
|---|---|
| 参数邻域细检 | 围绕当前参数按 ×[0.6, 0.8, 1.0, 1.25, 1.5] 伸缩（整数参数取整）；**悬崖** = 单维相邻档位跌幅 > 50%（此前为正值）；**稳健占比** = 邻域中收益 ≥ 70%·最佳的格数占比；**孤峰** = 当前参数为正、而单维紧邻点多数为负 |
| 蒙特卡洛 · 信号重排 | 打乱 signal 序列（**保留多空天数分布**）重跑 N 次；分位 = 实际收益在随机分布中的位置（≥90 通过） |
| 蒙特卡洛 · Bootstrap | 权益日收益 iid 重采样重建 N 条路径 → 收益 / 回撤分位数；iid 忽略自相关，作为粗略参照（口径已标注在报告里） |
| 成本敏感性 | 手续费直接乘倍数；滑点经 `tick_size × 倍数` 缩放（保持 `slippage_ticks` 整数约定）；**归零点**由相邻档位线性插值 |
| Deflated Sharpe | Bailey & López de Prado (2014)；试验次数 = `strategy.grid` 有效组合数；夏普统一「每期」口径（年化 ÷ √252） |
| 样本外使用次数登记 | `output/oos_usage.json`，键 = 品种｜策略｜分段；>3 次时样本外结论自动降级为「存疑」 |
| 统计函数 | 全部自研（`stats_utils.py`：Φ / Φ⁻¹（Acklam）/ 偏度 / 峰度），**未新增任何第三方依赖** |

## 3. 判定阈值（默认值；`config.health_check.thresholds` 可覆盖）

| 体检项 | 通过 | 存疑 | 不通过 |
|---|---|---|---|
| 样本外验证 | 测试段收益 > 0 且夏普 > 0 | 仅收益 > 0；或使用次数 > 3 | 收益 ≤ 0 |
| 参数敏感性 | 无悬崖且稳健占比 ≥ 60% | 有悬崖或占比 < 60% | ≥2 处悬崖或孤峰 |
| 蒙特卡洛对照 | 分位 ≥ 90 | ≥ 70 | < 70 |
| 成本敏感性 | 归零点 ≥ ×3（或 ×3 仍为正） | ≥ ×1.5 | 否则 / 基准已为负 |
| Deflated Sharpe | DSR ≥ 0.95 | ≥ 0.90 | < 0.90 |

总判定 = 各项最差（跳过项不参与）。

## 4. 代码结构

新增 `src/analysis/`（7 个模块）：

- `stats_utils.py` —— 轻量统计（Φ / Φ⁻¹ / 偏度 / 峰度）
- `deflated_sharpe.py` —— DSR（期望最大夏普 + 校正）
- `param_sensitivity.py` —— 邻域细检（悬崖 / 孤峰 / 稳健占比）
- `monte_carlo.py` —— 信号重排对照 + 收益 Bootstrap
- `cost_sensitivity.py` —— 成本放大复跑 + 归零点插值
- `oos_usage.py` —— 样本外使用次数登记
- `health.py` —— 编排 + 逐项判定 + 总判定

修改：`run_backtest.py`（集成 + 图表 / CSV 输出）、`src/report/report.py`（`build_health_table`）、`src/report/plotter.py`（3 张新图表）、`config/config.yaml`（`health_check` 段）、`pyproject.toml`（1.1.0）、`CHANGELOG.md`。

## 6. 验证记录（2026-10-09）

- 单元测试：**39/39 通过**（新增 18 个：统计函数 / DSR / 悬崖 / 邻域 / 蒙特卡洛可复现 / Bootstrap / 成本缩放 / 插值 / 判定 / 使用登记与降级）。
- 代码规范：`ruff check .` 全过。
- 端到端：`uv run python run_backtest.py`（玉米 C0 · dual_ma 5/20）全程 **≈ 15–18s**（含 150 次信号重排 + 500 条 Bootstrap + 25 格邻域 + 4 档成本 + 9 次 DSR 试验）。
- 样例体检结论（首跑）：总判定「**不通过**」——DSR = 0.549（9 次试验校正后不显著）；参数邻域稳健占比 28%、成本 ×2.49 归零 → 两项存疑；蒙特卡洛 100 分位、样本外通过。**这是一份「诚实」的结果**：策略的择时信息量存在，但在多重试验与成本口径下经不起全部检验。这正是体检要暴露的东西。

## 7. 边界与已知限制

- Bootstrap 为 iid 口径，忽略收益自相关；
- 邻域伸缩为乘法近似（非任意步长网格）；
- 样本外使用次数为**本机**登记（`output/oos_usage.json`，不进版本库）；
- 数据质量校验、数据库化属 v1.4 范围，本版未涉及。
